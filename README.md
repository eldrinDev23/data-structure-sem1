# Data Structures Using C

## Description
This repository contains implementations of various Data Structures and Algorithms using the C programming language. These programs are created as part of MCA lab practice to understand and implement fundamental concepts.

## Programs Included

1. **AVL Tree** – Self-balancing Binary Search Tree.
2. **BFS** – Breadth First Search graph traversal algorithm.
3. **B-Tree** – Balanced tree data structure.
4. **DFS** – Depth First Search graph traversal algorithm.
5. **Dijkstra's Algorithm** – Finds the shortest path between vertices in a weighted graph.
6. **Disjoint Set** – Manages disjoint groups using Union and Find operations.
7. **Graph** – Implements graph data structures and operations.
8. **Hash Table** – Stores and searches elements using a hash function.
9. **Kruskal's Algorithm** – Finds the Minimum Spanning Tree (MST).
10. **Min-Max** – Finds the minimum and maximum elements.
11. **Prim's Algorithm** – Finds the Minimum Spanning Tree (MST).
12. **Red-Black Tree** – Self-balancing Binary Search Tree.
13. **Segment Tree** – Supports efficient range queries and updates.
14. **Topological Sort** – Arranges vertices of a directed acyclic graph in topological order.
15. **Trie** – Tree-based data structure used for storing and searching strings.

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## How to Run

**1. Compile a C program**

```bash
gcc filename.c -o program.exe
```

**2. Execute the program**

```bash
./program.exe
```

Replace `filename.c` with the required C file name.
