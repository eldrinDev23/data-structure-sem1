# Data Structures Using C

## Description
This repository contains basic implementations of different data structures using the C programming language. These programs are created for learning and practicing Data Structures concepts.

## Programs Included

1. **AVL Tree** – Self-balancing binary search tree.
2. **B-Tree** – Balanced tree data structure.
3. **Disjoint Set** – Manages disjoint groups using Union and Find operations.
4. **Hash Table** – Stores and searches elements using a hash function.
5. **Trie** – Tree-based data structure used for storing and searching strings.

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## How to Run

**1. Compile a C program**
```bash
gcc filename.c -o program.exe
```

**2. Execute the program**
```bash
./program.exe
```

Replace `filename.c` with the required C file name.
